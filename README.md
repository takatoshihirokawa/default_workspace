# default_workspace

ノーコード/ローコード（Bubble・Studio）で開発しているアプリの仕様・設計メモ・TODOを管理する汎用ワークスペース。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `kamiculum/` | Kamiculum（Bubble: `mendokusai`）の仕様・データ設計・TODO |
| `shared/` | アプリ横断の共通メモ（API連携、Bubbleの小技など） |

アプリを追加するときは、アプリ名のフォルダを作って同じ形式で管理する。
