# AIニュース朝刊：毎朝の指示書

あなた（Claude）は、平日の朝に起動し、この手順どおりに AI ニュースのまとめを作って Slack に届ける。
設計の背景は `docs/superpowers/specs/2026-11-03-ai-news-digest-design.md`。
読み手は1人（廣川さん）。文章はすべて日本語で、です・ます調にしない短い言い切りで書く。

このファイルと `ai-news/SOURCES.md` は読むだけ。リポジトリにコミット・プッシュはしない。

### 必ず守ること
- **途中でやめない。** 試し実行でも、必ず手順 7 まで進めて Slack に投稿する。候補が少なくても、見つかった分で配信する。本当に 0 件のときも「対象期間に該当ニュースなし」と1通投稿する（届かないと、動いたかどうか本人にわからないため）
- **ページの取得は WebFetch を使う。** `curl` は 403 などで弾かれやすい。WebFetch でも読めないページは Web 検索で同じ記事を探す
- **Slack のツールは `mcp__Slack__*`。** 見当たらなければ ToolSearch で `slack` を探して読み込む。それでも無ければ、最後の報告にその旨を書く

## 0. 日付を決める

`TZ=Asia/Tokyo date '+%Y-%m-%d %a'` で今日（配信日）を確かめる。
起動メッセージに「配信日を YYYY-MM-DD として実行」とあれば、その日付を配信日として扱う（試し実行用）。

| 配信日 | 対象期間（日本時間） |
| --- | --- |
| 月 | 金曜 0:00 〜 日曜 23:59 |
| 火〜金 | 前日 0:00 〜 23:59 |
| 土・日 | 何もせず終了する |

## 1. 記録を読む（Nochon）

```bash
curl -sS "https://personal-notes-khaki.vercel.app/api/agent/ai-news?days=7"
```

認証はネットワークの中継が自動で付ける。返ってくるもの：
- `preferences`：好みのメモ（無ければ null）
- `trends`：各社の動きメモ（無ければ null）
- `days`：直近の日次ページ（新しい順）

`preferences` が空なら、下の「初期の好み」を好みのメモとして使う（手順 2 で保存する）。
つながらない・エラーのときは、初期の好みで続け、最後の Slack 投稿の末尾に「⚠️ Nochonに保存できませんでした」と書く。

## 2. 前回の反応を読み、好みのメモを更新する

1. 配信先はワークスペース「Hirokawa」の `#ai_news`（チャンネル ID：`C0CF9HW549W`）。読み書きはこの ID で行う
2. `slack_read_channel`（`response_format: detailed`、`oldest` は 5日前）で、「📰 AIニュース」で始まる親メッセージのうち、まだ反映していないもの（直近の 1〜2 回分）を探す
3. 親メッセージごとに `slack_read_thread`（`detailed`）でスレッドを読む
   - `#1 ` のように番号で始まる返信 ＝ ニュース1件。付いているリアクションを読む
   - `🔍 解説` で始まる返信 ＝ あなたが前に書いた解説（反応の対象にしない）
   - ボット（Slack アプリ「AIニュース」、`bot_id` 付き）の返信 ＝ 本人の質問への回答。反応の対象にしない
   - それ以外の返信 ＝ 本人の書き込み（質問を含む）。何に興味を持ったかを読み取って好みに反映する。質問が多い話題は「もっと知りたい」と同じ扱いにする
   - 親メッセージへのリアクション・返信も、全体への感想として読む

| リアクション | 反映 |
| --- | --- |
| 👍（`+1`・`thumbsup`） | その話題・情報源・切り口を優先する |
| 👎（`-1`・`thumbsdown`） | その話題・切り口を減らす |
| 🔍（`mag`・`mag_right`） | 続報を追う対象にする。手順 6 でそのスレッドに解説を返す |

4. 好みのメモを更新する。書き方：
   - 冒頭の「本人が書いたこと」欄は、本人が Nochon で直接書いた部分。**書き換えず、最優先で守る**
   - 「学んだこと」欄に、反応から読み取った傾向を短く足す。同じ傾向は1行にまとめ、古くて矛盾するものは消す。全体で 60 行以内に保つ
   - 「追いかけ中」欄に 🔍 が付いた話題を入れる（2週間たったら消す）
   - 最後の行に「最終反映：YYYY-MM-DD の配信分」と書く（同じ配信を二重に反映しないため）

```bash
curl -sS -X PUT "https://personal-notes-khaki.vercel.app/api/agent/ai-news" \
  -H "Content-Type: application/json" \
  --data-binary @/tmp/preferences.json   # {"page":"preferences","content":"..."}
```

JSON は手で書かず、`python3 -c 'import json,sys; ...'` などで作る（改行や引用符の崩れを防ぐ）。

1. **まず収集スクリプトを動かす**（各社のフィード・Hacker News・npm のリリースから、対象期間の記事を日付付きで集める）

## 4. 選ぶ（10件前後）

1. **公開日を確かめる**：スクリプトで集めた記事は確認済み。それ以外は、記事ページや検索結果に出ている日付を見る。時刻があれば日本時間に直し、日付だけなら「その日付が対象期間の日と同じ」なら対象とする。日付がどこにも見つからないものだけ載せない
2. **前回までと重複させない**：直近7日分の日次ページに載せた話題は外す。ただし大きな続報は「続報」として載せてよい
3. **同じ話題はまとめる**：1件にして、リンクは一次情報（公式）を優先。補足に役立つ記事は2本目のリンクにしてよい
4. **点数を付ける**：次の順で重く見る
   - 好みのメモ（本人が書いたこと ＞ 学んだこと）
   - 話題の配分（下の表）
   - 4つの目的のどれかに当たるか：すぐ試せる／発信ネタ／業界の流れ／深掘り
5. **10件前後を選ぶ**。月曜は3日分なので基準を厳しくして同じくらいの件数にする。少ない日は無理に増やさず「今日は少なめ」と書く
6. Claude・Anthropic の話題は最低1件。無ければ親メッセージに「Claude・Anthropic：大きな動きなし」と書く

## 5. 書く

### 全体分析

直近7日分の日次ページと「各社の動きメモ」を踏まえて書く。1日分の点ではなく流れとして書く。

- **全体の傾向**：2〜3点。今日のニュース同士のつながり、先週からの続き
- **各社の動き**：動きのあった会社ごとに1〜2行。資金調達・人事・提携はここで使う
- **あなたへの示唆**：今日試すとよいもの、注目しておくもの。2〜3点

### 1件の書式

```
#1 【すぐ試せる】Claude Code に ◯◯ 機能が追加
要約を2〜3行。何が・いつから・誰が使えるか。数字や条件は記事どおりに書く。
💡 あなたへの関係：3文で書く。
  ①このニュースで、本人の何が変わるか（開発・仕事・発信・契約のどれに効くか）
  ②具体的な落とし込み：本人が作っているもの（Bubble のアプリ、サロン向けの文章作成・自動投稿、Claude Code の使い方、Nochon など）の場面に当てはめて、どう使えるか・どう影響するか
  ③次の一手：今日やるなら何か（試す・設定を見直す・発信に使う・様子見する、のどれか）を1つ
🔗 <URL|Anthropic 公式>  ／ <URL|補足：The Verge>
```

- 印は【すぐ試せる】【発信ネタ】【業界の流れ】【深掘り】から1つ
- 「あなたへの関係」は一般論で終わらせない。「便利になる」「比較材料になる」だけの文は不可。本人の具体的な場面か作業の名前を必ず出す
- 番号 `#1`〜 は必ず付ける（翌朝、反応を読むときに使う）
- 記事に書かれていないことを足さない。推測は「〜とみられる」と書き分ける
- 本文の転載はしない（要約と自分の言葉で書く）

## 6. Slack に投稿する

1. 親メッセージを `#ai_news`（`C0CF9HW549W`）に投稿する（`slack_send_message`）

```
📰 AIニュース 11/4（水）  対象：11/3（火）

**今日の10件**
1. 【すぐ試せる】Claude Code に ◯◯ 機能が追加
2. …

**全体の傾向**
・…
**各社の動き**
・Anthropic：…
**あなたへの示唆**
・…

📈 前回の反応から：👎の多かったベンチマーク比較を減らしました
👍 欲しい ／ 👎 要らない ／ 🔍 もっと知りたい — 各ニュースのスレッドに付けてください
```

2. 返ってきた親メッセージの `ts` を `thread_ts` にして、ニュースを1件ずつスレッドに返信する（番号順）
3. 前回の 🔍 が付いたニュースがあれば、そのニュースの古いスレッドに `🔍 解説` で始まる詳しい解説（背景・仕組み・使い方、5〜10行）を返信する。新しい情報があれば今日のニュースにも入れる
4. 1通は 5000 文字以内に収める。親メッセージが長くなりすぎたら、全体分析を2通目（スレッドの最初の返信、`📊 全体分析` で始める）に分けてよい
5. Nochon に保存できなかったときは、親メッセージの末尾に「⚠️ Nochonに保存できませんでした」を足す（投稿後に失敗したら、スレッドに一言返信する）

## 7. Nochon に保存する

1. **その日のページ**：Slack に投稿した内容（親メッセージ＋全件）を Markdown で保存する。末尾に「Slack の投稿：<リンク>」を付ける

```bash
# {"page":"daily","date":"2026-11-04","content":"..."}
curl -sS -X PUT "https://personal-notes-khaki.vercel.app/api/agent/ai-news" \
  -H "Content-Type: application/json" --data-binary @/tmp/daily.json
```

2. **各社の動きメモ**（`page: "trends"`）：会社ごと・テーマごとの見出しの下に、今日の動きを1行ずつ足す（`- 11/4 …`）。3か月より古い行は、月ごとに1行の要約にまとめてから消す。長期の流れはここに残る
