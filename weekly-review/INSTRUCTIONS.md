# 週次ふりかえり：指示書

あなた（Claude）は、毎週金曜の夕方に起動し、この手順どおりに1週間の作業ログを読み返して、AIのルール（CLAUDE.md・スキル）の改善案をNotionにまとめる。
読み手は1人（廣川さん）。文章はすべて日本語で、短く言い切る。

ねらい：使うほどAIの品質が上がるように、繰り返し起きた失敗・指摘・学びを、ルールとして定着させる（「AIエージェントの性能を爆上げする7つの技術」の1「セッション履歴からハーネスを改善する」）。

### 必ず守ること
- **提案するだけで、変更はしない。** どのリポジトリにもコミット・プッシュ・PR作成をしない。反映は、廣川さんが提案を読んで「入れて」と言ったときに別のセッションで行う。
- **記録にないことを作らない。** 提案には、根拠になった作業ログの記録（タイトルとリンク）を必ず付ける。
- **途中でやめない。** 記録が少なくても、必ず手順 4 まで進めてNotionにページを作る。
- Notionのツール（`mcp__Notion__*`）が見当たらなければ、ToolSearch で `notion` を探して読み込む。

---

## 0. 期間を決める

`TZ=Asia/Tokyo date '+%Y-%m-%d %a'` で今日を確かめる。対象期間は「今日を含む過去7日間」（日本時間）。

## 1. 作業ログを読む

Notionのデータベース「作業ログ」（データソース `collection://29667c75-313d-4220-bdf9-743a8b112333`）から、対象期間の記録をすべて読む。

```json
{"data": {"mode": "rows",
  "data_source_url": "collection://29667c75-313d-4220-bdf9-743a8b112333",
  "filter": {"type": "group", "operator": "and", "filters": [
    {"type": "property", "property": "日付", "propertyType": "date",
     "operator": "date_is_on_or_after", "value": {"type": "exact", "value": "<7日前の日付>"}}]},
  "sort": [{"property": "日付", "direction": "ascending"}],
  "limit": 100}}
```

- タイトルに【テスト】が付いた記録は無視する。
- あわせて、過去の「週次ふりかえり」ページ（Notionの「AI共通メモリ」の下）のうち最新の1つを読み、前回の提案と重ならないようにする。

## 2. いまのルールを確かめる

提案先になりうるルールを読む。

- default_workspace の `CLAUDE.md` と `.claude/skills/notion-memory/SKILL.md`（作業ディレクトリに無ければ `git clone --depth 1 https://github.com/takatoshihirokawa/default_workspace`）
- 記録の「リポジトリ」欄に出てきたリポジトリの `CLAUDE.md`（読めないものは読まなくてよい。その場合は提案に「中身は未確認」と書く）
- Notionのページ「AI共通メモリ」（https://www.notion.so/40fe4e613e19816aa099c8ae73cdb880 ）のルール

## 3. 改善案を考える

次のようなものを探す。

- 同じ種類の失敗・やり直し・「AIに何度も直させた点」が2回以上出ている
- 「学び」に書かれたが、まだどのルールにも入っていないこと
- 「課題」のうち、ルールを足せば次から防げるもの
- 守られていないルール（例：完成条件を決めずに作り始めた、PRを作ったのに記録がない）

提案は**最大5件**。1件ずつ次の形で書く。

| 項目 | 書き方 |
| --- | --- |
| 何を変えるか | 1行で |
| どこに入れるか | リポジトリ名とファイル（例：`zundamon-shorts` の `CLAUDE.md`）、またはNotionのルール |
| 入れる文面の案 | そのまま貼れる1〜3行 |
| 根拠 | 作業ログの記録のタイトルとリンク |
| 効果 | 何が防げる・良くなるかを1行で |

提案できるものが無いときは、無理に作らない。「今週は提案なし」と書き、理由（記録が少ない、問題が見つからない など）と、来週に向けて記録の書き方で直すとよい点があれば添える。

## 4. Notionにまとめる

Notionのページ「AI共通メモリ」（page_id `40fe4e61-3e19-816a-a099-c8ae73cdb880`）の下に、子ページを1つ作る。

- タイトル：`週次ふりかえり YYYY-MM-DD`（今日の日付）
- 中身：
  1. 今週の記録の件数（種類ごと）と、リポジトリごとの件数
  2. 改善案（手順 3 の表を1件ずつ。番号を付ける）
  3. 反映のしかた：「入れたい提案があれば、Claude Code で『週次ふりかえり YYYY-MM-DD の提案1と3を入れて』と言ってください」

## 5. 最後の報告

最後のメッセージ（スマホへの通知に使われる）に、次を3行以内で書く。

- 今週の記録の件数
- 改善案の件数と、いちばん効きそうな1件のタイトル
- 作ったNotionページのリンク
